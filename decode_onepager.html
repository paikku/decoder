.dd 파일 — 이렇게 읽는다
바이너리 TLV. 칸 하나 = 바이트 하나, 색은 역할입니다. 태그가 폭을 정하고, 컨테이너는 END(00) 로 닫힙니다. 모든 다바이트 수치는 big-endian.
매직 / 트레일러 Type 09 이름 SubType 값 컨테이너 END 00
01  파일 프레임
17 FA AE 4E 0B … 필드들 반복 … 00 BC 94 26 A8
MAGIC 4B 열기 최상위 STRUCT 본문 닫기 TRAILER 4B
파싱 전에 끝 4바이트를 먼저 떼어낸다 — 트레일러는 구조가 아니라 체크섬. 구조 영역은 raw[4 : n-4] 뿐이다.
02  필드 하나 = 네 조각
09 "lens_magnification" 00 08 3F D0 00 00 00 00 00 00
Type 이름 (ASCII) NUL SubType 1B 값 = 0.25 (float64)
이름 있는 필드는 항상 09 로 시작. SubType 자리의 09 는 "값이 문자열"이라는 뜻 — 같은 바이트지만 위치가 역할을 정한다.
03  중첩 — 여는 태그와 END 는 짝 (실측 예제) 
0B 09 "IFEUCM_..._struct" 00
  0B 09 "lens_magnification" 00 08 3F D0 00 …
     09 "if_sim_mode" 00 09 "SIM_DISABLED" 00
     09 "hw_timestamp_tx" 00 09 "TRUE" 00
  00  ← 안쪽 STRUCT 닫기
00  ← 최상위 닫기
 
{ "IFEUCM_…": {
    "lens_magnification": 0.25,
    "if_sim_mode": "SIM_DISABLED",
    "hw_timestamp_tx": "TRUE"
} }
STRUCT/ARRAY 는 값 자리에 자식들을 담고 END 로 닫는다. 들여쓰기가 곧 깊이 — 길이 필드는 없다.
04  배열 원소 — 이름 없이 SubType+값 반복
09 "es_values" 00 0A 05 23 3D 02 05 19 19 … 00
필드 이름 ARRAY 9021 0 6425 반복 닫기
원소는 이름이 없고, 각자의 태그로 폭이 정해지므로 폭이 섞여도 결정적이다 (int8 → 128↑ 는 enum 으로 승격). 예외는 09 원소 하나 — 이름 NUL 직후 바이트가 0A/0B 면 이름+컨테이너 원소, 아니면 맨 문자열 값.
05  SubType = 폭 사다리
태그 폭 읽는 법
00—END — 컨테이너 닫기
011Bint8 (희소)
02 / 030B값 0 — payload 없음 (실측 652/652)
041Bint8 — 진짜 int8 값은 여기
052Bint16
064Bint32 — "BOOL" 이란 이름은 유물
07 / 084B / 8BIEEE754 float (08 이 가장 흔함)
09가변문자열 — 00 까지
0A / 0B가변ARRAY / STRUCT — 00 으로 닫힘
이게 전부의 핵심 — 태그는 타입이 아니라 폭이다. 인코더는 값이 들어가는 최소 폭을 고르고, 값이 0이면 폭도 0이라 payload 자체가 없다. 같은 count 필드가 값에 따라 02(=0) → 04 05(=5) → 05 01 2C(=300) 로 태그가 바뀐다.
06  파싱 루프 — 이게 디코더 전부 
body, trailer = raw[4:-4], raw[-4:]   # 틀 먼저 벗기기

def read_members(p):               # 컨테이너 하나
    while body[p] != 0x00:         # END 면 닫는다
        p, name = read_name(p)      # 09 + 식별자 + 00
        st = body[p]; p += 1         # SubType 1B
        p, out[name] = read_value(p, st)
    return p + 1

def read_value(p, st):
    # 값 0 = 폭 0 → payload 가 아예 없다
    if KEY_ANCHOR.match(body, p):     return p, 0
    if body[p]==0x00 and st<=0x04: return p, 0
    if st in (0x0A,0x0B): return read_container(p,st)
    w = WIDTH[st]                     # 위 폭 사다리
    return p+w, decode_be(body[p:p+w])  # big-endian
앵커 /\x09[A-Za-z_][A-Za-z0-9_.\-]{0,63}\x00/ 로 "다음 필드가 시작됐나"를 본다. 이 두 줄이 빠지면 디싱크 — 뒤 필드가 통째로 사라진다. 2B 이상 태그에 END 검사를 안 하는 건 float 첫 바이트가 00 일 수 있어서.
