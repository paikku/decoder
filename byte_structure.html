.dd Binary TLV · Byte Layout

바이트 구조 한눈에

칸 하나 = 바이트 하나. 색은 역할입니다. 파일 전체 → 필드 하나 → 값의 폭 → 중첩 → 배열, 그리고 파서가 넘어지는 예외 4가지까지.

03

04

중첩 — 여는 태그와 END 는 짝

STRUCT/ARRAY 는 값 자리에 자식들을 담고 END(0x00)로 닫습니다. 들여쓰기가 곧 깊이입니다.

0B┐ 최상위 STRUCT 열기
09"outer_struct" 000B┐ 필드 값이 또 STRUCT → 한 단계 더
09"ratio" 00083F D0 00 00 00 00 00 00스칼라 필드
09"mode" 0009"SIM_DISABLED" 00문자열 필드
00┘ 안쪽 STRUCT 닫기
00┘ 최상위 STRUCT 닫기

SubType 자리의 0x09 는 "값이 문자열" 이라는 뜻 — 필드 시작의 0x09 와 같은 바이트지만 위치가 역할을 정합니다.

05

배열 원소 — 이름 없이 태그+값 반복

배열(0x0A) 안 원소는 이름이 없습니다. SubType(1B) + payload 만 반복하고 END 로 닫습니다.

06

수치 배열의 타입 승격 — 폭이 배열 중간에 바뀐다
